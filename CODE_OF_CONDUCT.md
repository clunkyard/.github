# Code of conduct

Treat people with respect. Keep feedback specific to the code, tactic or
result, and welcome questions from people learning their first language.

Harassment, discriminatory abuse, threats, doxxing and unwanted personal
attention are not welcome. Maintainers may remove disruptive content or
limit participation to keep Clunkyard useful and welcoming.

Use GitHub's **Report content** action on an issue, pull request or comment
to report abuse privately. GitHub also provides a
[private abuse-reporting form](https://support.github.com/contact/report-abuse).
See [GitHub's reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
for the available reporting options. Keep personal details out of public issues.
