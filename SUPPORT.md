# Help with Clunkyard

- **First robot:** follow the [tutorial](https://clunkyard.com/getting-started).
- **Rules, practice and competition:** read the [game manual](https://clunkyard.com/manual).
- **Robot code:** use the [SDK reference](https://clunkyard.com/sdk) and
  [local trials guide](https://clunkyard.com/sdk/local-trials).

Report a reproducible SDK or example bug in the affected repository. Include
the language profile, ruleset, expected result and the smallest source or
replay that demonstrates the problem. For a game or documentation issue
without a matching repository, use the
[organization's issue tracker](https://github.com/clunkyard/.github/issues).

Share only material you are comfortable making public. Keep API keys,
account tokens and private robot source out of issues and replays. Report
security vulnerabilities through the [private channel](SECURITY.md).
