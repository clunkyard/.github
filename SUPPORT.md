# Help with Clunkyard

Ask setup, language, tactics and local-match questions in
[Clunkyard's shared discussions](https://github.com/clunkyard/game-kit/discussions).
Players using any starter language are welcome there.

- **First robot:** follow the [tutorial](https://clunkyard.com/getting-started).
- **Rules, practice and competition:** read the [game manual](https://clunkyard.com/manual).
- **Develop locally:** choose a [language starter](https://github.com/clunkyard/game-kit),
  then build and compare changes with [local trials and replays](https://clunkyard.com/sdk/local-trials).
- **JavaScript or TypeScript:** install [@clunkyard/sdk](https://www.npmjs.com/package/@clunkyard/sdk)
  and follow the [SDK guide](https://clunkyard.com/sdk/javascript).
- **Private Git:** install [@clunkyard/git](https://www.npmjs.com/package/@clunkyard/git)
  and follow the [clone, sign-in and push guide](https://clunkyard.com/sdk/private-git).

Report a reproducible API, npm package or SDK example defect in the
[SDK issue tracker](https://github.com/clunkyard/sdk/issues/new/choose).
Report a starter, local-match or game-kit defect in the
[game-kit issue tracker](https://github.com/clunkyard/game-kit/issues/new/choose).
For a game or documentation issue without a matching repository, use the
[community issue tracker](https://github.com/clunkyard/.github/issues/new/choose).

Include the package version, language, operating system and toolchain, expected
result and smallest reproduction you can share. A ruleset, seed and public replay
can help explain a match problem.

Keep API keys, account tokens and private robot source out of public reports.
Report security vulnerabilities through the [private channel](SECURITY.md).
