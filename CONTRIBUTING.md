# Contributing to Clunkyard

Start with the README in the repository you want to change. Keep a pull
request focused on one useful improvement, explain the behaviour it changes
and include a runnable example or relevant checks.

For a robot tactic or SDK example, name the language profile, ruleset and
seed, and include the replay or steps needed to see the result. Compare a
working baseline before and after the change. The
[local trials guide](https://clunkyard.com/sdk/local-trials) shows the workflow.

For a bug, open an issue in the affected repository. Include the smallest
reproduction you can share. See [Support](SUPPORT.md) for game help and
[Security](SECURITY.md) for private vulnerability reports.

Be considerate and specific when discussing code, tactics and results. Our
[code of conduct](CODE_OF_CONDUCT.md) applies across Clunkyard repositories.
